## Описание проекта

TaskBoard — это веб-приложение для управления задачами, реализующее полный CRUD-цикл. Пользователь может:

- Просматривать список задач (невыполненные отображаются выше выполненных, внутри групп — сортировка по дате создания).
- Добавлять новые задачи с заголовком и описанием.
- Отмечать задачи как выполненные (визуальное перечёркивание).
- Редактировать название и описание задачи прямо в карточке.


## Возможности

- **Backend** REST API с методами GET, POST, PUT, DELETE, валидация моделей, асинхронные операции, автоматические миграции при запуске.
- **Frontend** динамическая отрисовка карточек, два режима отображения (просмотр / редактирование), локальное состояние (allTasks, activeFilter), защита от XSS (escapeHtml).

## Инструкция по запуску

### Требования
- [.NET SDK](https://dotnet.microsoft.com/download) (версия 8.0 или выше)
- Любой HTTP-сервер для фронтенда (например, Live Server в VS Code)

### Запуск бэкенда

1. Откройте терминал и перейдите в папку проекта `TaskBoardApi`:
   ```bash
   cd TaskBoardApi
2. Восстановите зависимости и соберите проект
    ```bash
    dotnet restore
    dotnet build
3. Запустите сервер
    ```bash
    dotnet run
### Запуск фронтенда
1. Откройте папку frontend в редакторе кода
2. Запустите index.html через Live Server
3. Убедитесь, что в файле frontend/js/api.js указан правильный базовый URL бэкенда (брать из терминала)
    ```bash
    const API_URL = "http://localhost:5000/api/tasks";
    ```

### Главные выводы


Асинхронное программирование – использование async/await как на сервере (FindAsync, SaveChangesAsync, ToListAsync), так и на клиенте (fetch, обработка ответов) значительно повышает отзывчивость приложения и предотвращает блокировку потоков.

Модульность фронтенда – разделение логики на api.js (сетевые запросы) и app.js (отрисовка, состояние, обработчики) упрощает поддержку и тестирование. Хранение всех задач в локальном массиве allTasks позволяет фильтровать данные без лишних запросов к серверу.
